# RealtimeX CLI and Skill Release

This branch is intentionally minimal. It contains only the release tooling needed
to generate and publish:

- `@realtimex/pp-cli`
- the `realtimex-moderator-sdk` skill release asset consumed by the app release
  pipeline

The TypeScript and Python SDKs are planned to return later as source-owned
packages. Generated OpenAPI specs, generated SDK modules, and generated skill
output are not committed here.

## GitHub Workflow

Use `.github/workflows/pp-cli-publish.yml`.

Manual inputs:

- `version`: release version, for example `2.0.18`
- `openapi_url`: downloadable OpenAPI spec generated by the app repo
- `openapi_sha256`: optional SHA256 digest for that spec

The workflow publishes `@realtimex/pp-cli` and uploads:

```text
realtimex-moderator-sdk-<version>.tar.gz
realtimex-moderator-sdk-<version>.tar.gz.sha256
```

The app GitLab release downloads those assets and injects the skill into the
packaged builtin plugin.
